# LEARNPLAYWRIGHTBATCH2x

A hands-on repository for learning Playwright and JavaScript concepts.

## Topics Covered

- **Chapter 1** — JavaScript Basics (variables, hot code)
- **Chapter 2** — JavaScript Concepts (data types, identifiers)
- **Chapter 3** — Identifier & Literals (naming conventions, comments, rules)
- **Chapter 4** — JavaScript Advanced Concepts (var, let, const, functions, hoisting)
- **Chapter 5** — Literals (null, undefined, template literals, strings)
- **Chapter 6** — Operators (arithmetic, comparison, logical, ternary, increment/decrement)
- **Chapter 7** — If-Else (conditionals, grade calculator, leap year)
- **Chapter 8** — Switch Statement (switch, grouping, real-time examples)
- **Chapter 9** — User Input
- **Chapter 10** — Loops (for, while, do-while, for-in, for-of)
- **Pramod_sir_Tasks** — Hands-on exercises (bug severity, build health, HTTP status codes)
